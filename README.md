# Aleksandar Petrović - Customer Success Portfolio

Recruiter-focused portfolio for Senior Customer Success, Retention and CS Operations opportunities.

## Pages

- `index.html` - positioning, selected outcomes and role fit
- `case-studies.html` - retention, expansion and CS Operations evidence
- `experience.html` - career timeline
- `skills.html` - expertise, tools and certifications
- `contact.html` - contact details and CV download
- `chatbot.js` - bilingual interactive portfolio guide

The site is static and designed for GitHub Pages. No build step is required.
